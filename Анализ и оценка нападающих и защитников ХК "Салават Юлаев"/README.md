# Анализ и оценка нападающих и защитников ХК «Салават Юлаев»

Пет‑проект по аналитической оценке игроков ХК «Салават Юлаев»: нападающих по связке «зарплата — очки» с разбиением на 4 зоны, защитников — по связке «время на льду — показатель полезности» с дополнительной раскраской по зарплате и блокированным броскам, а также отдельного сравнения по проведенным силовым приемам. Проект показывает, как с помощью pandas, matplotlib и простой сегментации можно быстро получить управленческие выводы из табличных данных.

## Цели проекта

- Сегментировать нападающих на 4 категории («Актив», «Звезда», «Молодые», «Пассив») по порогам: зарплата ≥ 30 млн ₽, очки ≥ 25.
- Оценить эффективность защитников через связь «время на льду — показатель полезности», выделив зоны «Актив» и «Пассив» (порог времени на льду — 16 минут).
- Визуализировать распределение игроков с дополнительной кодировкой цветом (зарплата, блокированные броски) и отдельными метриками (силовые приёмы).
- Сформировать воспроизводимый пайплайн: Excel → обработка → визуализация → выводы.
- Оформить проект как пример аналитического отчёта для BI‑задач: понятные пороги, зоны, интерпретация, воспроизводимость.

> Проект выложен в GitHub как часть портфолио для задач в BI, аналитике и работе с табличными данными.

## Что уже реализовано

### Нападающие

- Загрузка листа «статистика» из Excel (pandas).
- Расчёт дополнительных метрик и создание новых столбцов.
- Построение scatter‑графика: ось X — зарплата, ось Y — очки.
- Разбиение графика на 4 квадранта по порогам:
  - Зарплата - 30 млн ₽
  - Очки - 25 очков
- Зоны: «Актив», «Звезда», «Молодые/Резерв», «Пассив».
- Интерпретация: кто в какой зоне, какие выводы по эффективности.

## Результат анализа по нападающим:
На основании построенной матрицы «Зарплата — Очки» игроки распределены по четырем стратегическим зонам:

- Зона «Актив» (МАЛО ДЕНЕГ - МНОГО ОЧКОВ): 
        Игроки, демонстрирующие высокую результативность при умеренной стоимости контракта (зарплата ≤ 30 млн руб., очки ≥ 25). Сюда входят Жаровский, Сучков и Кузнецов М. Также можно отметить и Родуолда и Броссо - получают больше, находятся на границы с "Звезды". Это наиболее эффективные контракты команды, обеспечивающие максимальную отдачу на вложенный рубль.
> Родуолд, Броссо - между зонами "Актив" и "Звезды" - скорее всего будут просить прибавку в зарплате по завершению контракта.
- Зона «Звезды» (МНОГО ДЕНЕГ - МНОГО ОЧКОВ): 
        Ремпал (100 млн руб., 54 очка). Ремпал - главная звезда команды. Игрок с максимальной результативностью в команде (54 очка), оправдывает высокую зарплату результатом, который приносит на льду. Является ключевым игроком для достижения турнирных целей.
- Зона «Молодые/резерв» (МАЛО ДЕНЕГ - МАЛО ОЧКОВ): 
           Горшков, Алалыкин, Кузнецов. Наигрывать в матчах, давать возможности получать игровую практику в КХЛ. Присмотреться к игрокам, которые несколько лет подряд не прогрессируют и не выходят из этой зоны. Молодежь способная заменить игроков на травме, либо же для ротации состава  
- Зона «Пассив»(МНОГО ДЕНЕГ - МАЛО ОЧКОВ): 
        Игрок Ян (35 млн руб., 12 очков). Находится в зоне неэффективных трат. При высокой стоимости контракта результативность значительно ниже целевого порога. Рекомендуется пересмотр условий контракта или изменение игровой роли.
> Ян - стоит пересмотреть условия контракта или же запрашивать расторжение/обмен. 

> Итоговый вывод: Бюджетная политика ХК "Салават Юлаев" признана эффективной, текущий состав имеет хороший баланс. В зоне "Пассив" находится один игрок. Требуется корректировка по игроку из зоны «Пассив».

|-|--------|---|                                                              
|Варлов|Хороший игрок защиты, в зоне «Темные лошадки» (дешево, полезно)|Абсолютный лидер по физике. У него больше всех силовых. Отлично играет в "разрушение" атак соперника, ломает игру соперника у бортов. Если есть звено, которое нужно «запереть» в чужой зоне — Варлов хорошо справится с данной задачей|

|Зоркин|Ключевой защитник|Имеет высокий показатель полезности с высоким игровым временем. Много силовых и блокированных. Разноплановый защитник, который может быть полезным как в обороне, так и в атаке|
