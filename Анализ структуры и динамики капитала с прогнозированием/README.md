# Анализ структуры и динамики капитала с прогнозированием

Данный пет‑проект предназначен для ежемесячного учёта капитала, анализа структуры капитала и построения краткосрочных прогнозов. 
Проект помогает отслеживать динамику капитала, оценивать доли по категориям и получать прогноз общей суммы на 1–2 месяца вперёд.

## Цели проекта

- Автоматизировать расчёт ключевых метрик капитала из Excel‑таблицы.
- Визуализировать структуру капитала (круговая диаграмма по типам).
- Построить график динамики изменения активов и прогноз на 1-2 месяца.
- Показать процентные соотношения по категориям и прогнозную оценку капитала через 1-2 месяца. 
- Оформить воспроизводимый пайплайн (Jupyter + скрипты).

> Проект выложен в GitHub как часть портфолио для задач в аналитике.

## Что уже реализовано

- Загрузка и предобработка данных из Excel (pandas) с валидацией типов и дат.
- Расчёт метрик: общий капитал, капитал по типам "Актив", "Подушка", "Инвестиция", их процентное соотношение по категориям.
- Круговая диаграмма структуры капитала по типам (matplotlib).
- Линейный график динамики по типам капитала.
- Прогноз ожидаемой суммы на 2 месяца с помощью Prophet и диапазоном возможных значений (ДИ - 95%).
- Блок с интерпретацией прогноза и доверительными интервалами.

## Результат анализа:
- Категория "Актив" составляет ~24 %
- Категория "Подушка" составляет 17 % 
- Категория "Инвестиция" составляет ~59 % \

Категория "Подушка" и "Инвестиция" в динамике наблюдается рост (пусть и медленный), а в категории "Актив" после просадки в апреле-мае и спаду в августе наблюдается рост.
\

С вероятностью 95% в ноябре 2026 года будет лежать в диапазоне от 0.995 до 1.139 млн рублей. Есть 5% шанс, что сумма выйдет за эти пределы \
Прогнозируемая сумма через 2 месяца - __1 080 366 руб.__
